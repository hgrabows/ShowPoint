# Präsentation

- `src/` – Folien (`scenes*.tsx`, Bausteine in `ui.tsx`), Texte und Ablauf (`content.json`),
  Hinweise für Fragen (`begleittext.md`) und Umbau (`umbau-regeln.md`)
- `quellen/` – Material (.md, .txt, .pdf), in dem das Modell bei Fragen nachliest
- `out/` – gerendertes Video

Gezeigt und bearbeitet wird sie mit dem Präsentator: dort `npm run edit` starten und unter „Präsentation“ diesen
Ordner wählen. Dieser Ordner braucht kein eigenes `node_modules`. Video erzeugen: im Präsentator-Ordner `npm run render`.
